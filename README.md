
# Android String Operations App

A simple Android application that performs basic operations on user-input strings using MVVM architecture and XML-based UI.

## Features

- **Length** – Displays the length of the input string.
- **Reverse** – Reverses the input string.
- **Append** – Appends '123' to the input string.
- **Is Numeric** – Checks if the string contains only digits.
- **Clear** – Clears the input and output fields.
- **Validation** – Only alphanumeric input is allowed.

## Tech Stack

- **Language:** Kotlin
- **Architecture:** MVVM
- **UI:** XML-based layout
- **Lifecycle:** ViewModel, LiveData


## How to Build

1. Clone this repository:

   https://github.com/pinkyagrawal245/StringOperations
